\subsection*{Artifact availability}

The artifact for this work is publicly available at
\url{https://github.com/bhanuprakashvangala/SC26-AgenticAI4HPC}. It contains the
code used to generate and verify the OpenMP programs, measure thread-level
performance, reproduce the serial-projection analysis, evaluate the reward
formulations, and run \PRB. The repository also includes the frozen experiment
logs, measured results, figure-generation scripts, and instructions for
reproducing the analyses reported in this paper.

The current \PRB\ release contains the adversarial cases evaluated in this work
and is designed to be extensible: additional candidates and attack classes can
be incorporated as new reward formulations and failure modes are studied. The
released artifact separates generated data and measured results from model-access
credentials so that the main analyses can be inspected and reproduced without
exposing private authentication information.

\subsection*{Artifact contents}

The released artifact contains the frozen generated-program pool and the
measurements used by the paper. The principal files are
\texttt{results/pareval\_runs.jsonl} for verification results,
\texttt{results/scaling.jsonl} for per-thread runtime measurements,
\texttt{results/sanitizer.jsonl} for Archer/ThreadSanitizer cross-checks, and
\texttt{logs/pareval/generations/} for the original prompts, model responses,
and extracted source programs. These files allow the main analysis to be rerun
without contacting the original model services.

\subsection*{Reproduction}

The recommended artifact-evaluation path uses the frozen measurements:
\begin{enumerate}
  \item \texttt{python -m pip install -r requirements.txt}
  \item \texttt{python -m harness.analyze\_scaling}
  \item \texttt{python -m agent.compute\_numbers}
  \item \texttt{python -m agent.parallel\_reward\_bench}
  \item \texttt{python -m agent.make\_paper\_figs}
\end{enumerate}
These commands reproduce the analysis and reward comparisons without requiring
model inference. Full regeneration of the generated programs additionally
requires access to the configured model endpoints and an OpenMP execution
backend; credentials are intentionally not included in the repository.

\subsection*{Software and hardware}

The analysis scripts require Python and the packages listed in
\texttt{requirements.txt}. Compilation and timing use GCC with
\texttt{-O3 -fopenmp}; the independent race-detection cross-check uses LLVM
Archer/ThreadSanitizer. Performance measurements are machine-dependent, so the
released timing data serve as the provenance record for the values reported in
the paper. The timing protocol fixes thread placement and repetitions as
described in Section~\ref{sec:setup-protocol}.

\subsection*{Reproducibility boundaries}

Statistics and reward comparisons derived from the released JSON/JSONL files are
deterministic. Re-running the compiled programs on different hardware can change
absolute runtime and speedup values, while re-running hosted models can produce
different source text as model services evolve. For this reason, the artifact
preserves both the original generation logs and the frozen measurements used in
the reported experiments.
