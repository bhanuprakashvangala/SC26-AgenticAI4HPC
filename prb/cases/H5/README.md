# H5 — Sequential Algorithmic Speedup

H5 contains functionally correct cases that achieve strong reference-relative performance through a better sequential algorithm rather than meaningful thread scaling.

## Purpose

Tests the distinction between reference speedup and parallel scaling.

## Required evidence per case

- construction or implementation details;
- whether the case is executed or modeled;
- correctness verdict;
- reference and self-speedup measurements when executed;
- reward scores.

Modeled cases must be labeled explicitly and must not be counted as executed programs.
